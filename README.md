# cal_paste · 财务快贴

**按住 CapsLock，选中数字就地算完直接贴** —— 给财务的 Windows 剪贴板计算器。

不用再 复制 → 切计算器 → 算 → 复制 → 切回来：选中数字按一个键，原地变成结果。
AutoHotkey v2 单文件（约 450 行），无需安装任何运行库。

## 功能一览

以下为默认键位，**全部可自定义**（见文末）。所有热键 = 按住 CapsLock 再按字母，单按 CapsLock 仍是正常大小写切换。

| 按键 | 功能 | 说明 |
|---|---|---|
| `CapsLock+A` | 加法粘贴 | 选中数字 → 原地变成「数 + 变量」；没选中 → 直接粘贴变量本身 |
| `CapsLock+C` | 设变量 | 选中一个数字按此键，它就是新的变量（加减乘除共用） |
| `CapsLock+S` | 正负切换 | 变量变号，如 +3000 ↔ -3000（红字冲销） |
| `CapsLock+M` | 乘法粘贴 | 选中数 × 变量（如税率 1.13） |
| `CapsLock+D` | 除法粘贴 | 选中数 ÷ 变量 |
| `CapsLock+W` | 元→万元 | 复制 25000 → 按键 → 粘出 2.5 |
| `CapsLock+Y` | 万元→元 | 复制 2.5 → 按键 → 粘出 25000 |
| `CapsLock+K` | ÷1000粘贴 | 元→千元、毫米→米，同套路 |
| `CapsLock+X` | 累加 | 选中数字记入累计（**不粘贴**），气泡实时报合计 |
| `CapsLock+Z` | 贴合计 | 把累计总和粘贴出来，同时累加器清零 |

每次操作鼠标旁都有气泡显示实际算式，算没算错一眼可见。

## 安装（2 分钟）

1. 安装 AutoHotkey v2：[autohotkey.com](https://www.autohotkey.com/) 下载，一路下一步
2. 下载本仓库的 `cal_paste.ahk`，**双击运行** —— 托盘出现绿色 **H** 图标即成功
3.（可选）开机自启：右键 `cal_paste.ahk` → 创建快捷方式 → `Win+R` 输入 `shell:startup` → 把快捷方式剪切进去

> 国内网络打不开下载页时，用镜像（如 `ghproxy.com` 前缀）或代理访问 raw 页面。

## 3 个典型场景

1. **每笔金额都要 +3000**：选中 3000 按 `C` 设为变量 → 之后每次选中数字按 `A`，一步到位
2. **元 ↔ 万元**：复制 25000 按 `W` 粘出 2.5；反向按 `Y`
3. **一页上散落的十个数求和**：逐个选中按 `X`（气泡实时报合计）→ 光标点到放结果的位置按 `Z`，合计贴出并清零

## 自定义按键（不用改代码）

记事本打开 `config.ini`，改等号右边的字母，托盘图标右键 →「重新加载配置」即生效。

- 换前缀：`prefix=CapsLock` 可改 `CtrlAlt` / `CtrlShift` / `AltShift` / `CtrlAltShift`
- 某个功能不想要：等号右边留空即关闭
- 想要独立热键：填 `F1`~`F12`（不受前缀影响）
- 键打冲突了启动时会弹窗告诉你，照提示改回即可

## 细节（你可能关心）

- **你的剪贴板永不被覆盖**：所有操作（含中途出错）结束后自动还原你原来的剪贴板
- 千分位逗号（`3,000` / `3，000`）、货币符号自动忽略；浮点尾数自动抹平
- 变量和累加器存在 `config.ini`，重启电脑不丢
- 每次操作前会先模拟一次 Ctrl+C 读取选中内容（0.6 秒等待，兼容慢软件）
