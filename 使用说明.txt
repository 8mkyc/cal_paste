  cal_paste 脚本 使用说明
══════════════════════════════════════════════

一、安装（一次性，约 2 分钟）
  1. 下载 AutoHotkey v2，官方地址：
     https://www.autohotkey.com/download/ahk-v2.exe
  2. 双击安装，一路下一步；若让你选版本，选 v2
  3. 双击本目录的 cal_paste.ahk
     → 屏幕右下角托盘出现绿色 H 图标 = 成功

  三个常见小问题：
  ※ 双击 .ahk 变成记事本打开？右键文件 → 打开方式 →
    选 AutoHotkey Launcher，勾选"始终使用此应用"
  ※ 杀毒软件弹窗拦截？属于误报，点信任/加白名单
  ※ 电脑装不了软件（无权限）？官网下载页有免安装的
    AutoHotkey_2.x.x.zip，解压后把 cal_paste.ahk 拖到
    解压出的 AutoHotkey64.exe 图标上即可运行

  开机自启（可选）：右键 cal_paste.ahk → 创建快捷方式；
  按 Win+R 输入 shell:startup 回车，把快捷方式剪切进去。

────────────────────────────────────────────
二、AHK 基础常识（第一次接触先看这里）
────────────────────────────────────────────
  · AutoHotkey（简称 AHK）是 Windows 上的免费小工具，
    作用是自定义热键和自动化动作，财务填表提效很常用
  · cal_paste.ahk 是文本文件（记事本能打开能改），
    但改按键不用碰它——按键全部写在 config.ini 里（见第六节）
  · 程序在跑的标志 = 托盘有绿色 H 图标；退出 = 右键 → Exit
  · 本工具所有热键都是「按住 CapsLock 再按字母」：
    CapsLock 在这里相当于一个前缀键，单按它仍是原来的
    大小写切换，不影响正常打字
  · 出问题先排查三件事：
    1) 托盘有没有绿 H（没有 = 程序没在跑，重新双击）
    2) 是否已选中内容（多数操作要先双击选中数字）
    3) 每次操作鼠标旁有气泡显示实际算式，看一眼就知道
       变量设成了什么、算的是不是你想要的

────────────────────────────────────────────
三、快捷键总表
────────────────────────────────────────────
  ※ 以下为默认按键，全部可以自定义，改法见第六节
  ※ 若你的 config.ini 里改过键，以你改的为准
  ※ Ctrl+C / Ctrl+V = 系统原生复制粘贴，本工具完全不碰

  CapsLock+A  加法粘贴：选中数字 → 原地变成 (数 + 变量)
              没选中   → 直接粘贴变量本身
  CapsLock+C  设变量：选中一个数字按此键，它就是新的变量
  CapsLock+S  变量正负切换（+3000 ↔ -3000）
  CapsLock+M  乘法粘贴：选中数字 → 原地变成 (数 × 变量)
  CapsLock+D  除法粘贴：选中数字 → 原地变成 (数 ÷ 变量)
  CapsLock+W  元→万元：Ctrl+C 复制金额 → 按此键粘贴 ÷10000 的结果
  CapsLock+Y  万元→元：Ctrl+C 复制万元数 → 按此键粘贴 ×10000 的结果
  CapsLock+K  ÷1000粘贴：Ctrl+C 复制数字 → 按此键粘贴 ÷1000 的结果
              （元→千元、毫米→米等同理）
  CapsLock+X  累加：选中数字按此键记入累计（不粘贴），气泡实时报合计
  CapsLock+Z  贴合计：把累计总和粘贴出来，同时累加器清零

────────────────────────────────────────────
四、常用场景
────────────────────────────────────────────
  1. 每笔金额都要 +3000
     找到 3000 → 选中 → CapsLock+C（变量=3000）
     之后每次：选中原数 → CapsLock+A，一步到位

  2. 元 ↔ 万元 换算
     Ctrl+C 复制 25000 → CapsLock+W → 粘出 2.5
     Ctrl+C 复制 2.5   → CapsLock+Y → 粘出 25000
     ※ 换算类键粘完会自动还原剪贴板，连按结果不会翻倍

  3. 税率换算（税率 13% 时，变量设为 1.13）
     找到 1.13 → 选中 → CapsLock+C（变量=1.13）
     含税 → 不含税：选中含税金额 → CapsLock+D（÷1.13）
     不含税 → 含税：选中不含税金额 → CapsLock+M（×1.13）
     ※ 变量是 A/M/D 共用的，用完税率记得把变量改回加减额
     ※ CapsLock+S 会把变量变号，税率模式下别乱按

  4. 红字冲销（负数）
     CapsLock+S 一键把变量翻转成负数，配合 A 键使用

  5. 一页上散落的多个数求和
     逐个选中数字 → CapsLock+X（每按一次气泡报当前合计）
     加完 → 光标点到要放结果的位置 → CapsLock+Z 贴出合计并清零
     ※ 累加支持负数（红字冲减直接 X 进去即可）

────────────────────────────────────────────
五、注意事项
────────────────────────────────────────────
  · 变量只随 CapsLock+C 改变，普通 Ctrl+C 不影响它
  · 金额的千分位逗号（3,000 或 3，000）、货币符号会自动忽略
  · 任何操作结束后，你的剪贴板都会原样还原，不会被覆盖
  · 浮点尾数（如 113.00000000000001）会自动抹平
  · 变量和累加器保存在同目录 config.ini，重启电脑不丢

────────────────────────────────────────────
六、怎么改快捷键（不用改代码）
────────────────────────────────────────────
  所有按键都记录在 config.ini 里，记事本就能改：
  1. 双击托盘绿 H 图标（或右键 → 打开按键配置）
     → 记事本打开 config.ini
  2. 改等号右边的字母，例如把 add=A 改成 add=Q
  3. 保存文件，托盘图标右键 → 重新加载配置，立即生效

  进阶玩法：
  · prefix=CapsLock 可改成 CtrlAlt / CtrlShift / AltShift，
    所有热键变成对应组合键（如 CtrlAlt 后，加法就是 Ctrl+Alt+A）
  · 某个功能不想要 → 等号右边留空，即关闭该功能
  · 想要独立热键 → 填 F1~F12（不受前缀影响）
  · 改错了启动时会弹窗指出是哪个功能的哪一项，照提示改回即可
